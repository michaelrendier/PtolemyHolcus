### The biology, compressed

- Silk is a block copolymer: **poly-alanine → β-sheet nanocrystals** (2–3 nm,
  stiff, tensile strength) in a **glycine-rich amorphous matrix** (hidden
  length, extensibility, toughness). Small crystals out-tough large ones.
- **N-terminal domain** = a pH sensor: monomeric/soluble at pH ≈ 7 (storage),
  **dimerises** below pH 5.7 in the duct (glutamate protonation) → daisy-chains
  spidroins into one network. Context-triggered link.
- **C-terminal domain** = a permanent disulfide-locked dimer made in storage;
  pre-aligns the repeats, converts to β-sheet on spinning. Always-on link.
- **Spinning is pultrusion, not extrusion**: the dope is drawn through a tapered
  duct — ion exchange (Na⁺/Cl⁻ out, K⁺/PO₄/SO₄ in), acidification, water
  reabsorption, elongational shear → liquid-crystal → β-sheet. You cannot
  crystallise by sitting still, only by being pulled.
- Silk is **tougher than Kevlar** though weaker than steel in tensile strength;
  the win is toughness (area under the curve) and strength-to-weight.

### The composition operators

| operator | web part | silk | job |
|---|---|---|---|
| `ANCHOR` | attachment point | piriform disc | an external load-bearing given / cite |
| `BRIDGE` | first spanned line | major ampullate | the thesis line |
| `FRAME` | boundary polygon | major ampullate | the scope |
| `HUB` | the Y-junction | strengthening silk | the core idea = **the zero-divisor reframe of the input** |
| `RADIUS` | one spoke | major ampullate | one intersectional axis, one straight through-line; each new radius re-tensions the others |
| `SCAFFOLD_SPIRAL` | auxiliary spiral, centre→out | minor ampullate | the **outline**, `reach` loops deep; disposable |
| `CAPTURE_SPIRAL` | capture spiral, out→in | flagelliform + aggregate | the **prose**; one arc = one paragraph, one loop = one section |
| `ELABORATE` | — | flagelliform | extensible connective, no hard claim, pure give |
| `HOOK` | sticky droplet | aggregate | an example / number / phrasing; hygroscopic |
| `WRAP` | swathing | aciniform | the recap that binds a captured idea; used at loop ends |
| `SHELL` | egg case | tubuliform | abstract / framing / provenance; written once |
| `SIGNPOST` | — | minor ampullate | "we return to this below" |

**Idea grammar (spidroin blocks):** `CRYSTAL(claim)` (poly-Ala, small & exact) ·
`SLACK(elaboration)` (amorphous hidden length) · `TRANSITION(on=context)` (NTD
pH-switch — a "however/therefore" that fires only when local conditions are
right) · `BIND(structural)` (CTD dimer — the always-on section skeleton). A
sentence reads `BIND — SLACK — CRYSTAL — SLACK — CRYSTAL — SLACK — TRANSITION`.

**Per-unit pipeline (the duct):** `STORE → SELECT_DEPS → COMMIT_FRAMING →
COMPRESS → DRAW → FINISH`.

### The connective lexicon (semantic domain)

A ~closed class (Halliday & Hasan conjunctive relations / PDTB explicit
connectives). Each class binds to a silk operator **and a radial move**:

| class | example | move |
|---|---|---|
| elaborate / exemplify / throughline | specifically, for example, therefore | **+1 outward** (next scaffold ring) |
| wrap / return | in sum, to return to | **−1 inward** (up a level, to the hub) |
| lateral | and, next, similarly | **0** (next spoke, same ring) |
| reverse / concessive | but, however, that said | **pivot** (frustrated-spiral reversal) |

The connective a unit **ends on** is the composition control signal — it names
where the next unit goes on the web.

### The two packings

- **E8 lattice = content packing / full-document evaluation.** 8-D, kissing 240,
  self-dual. Superimpose hyperspheres — one per `.bin`, per rule set, per UDEO
  response-curb. A finished document is a lattice point; its 240 neighbours =
  240 constraints checked at once; self-duality → content and check are one
  lattice. Static, crystalline, complete (θ = `E₄`, provably optimal).
- **Apollonian gasket = context flow.** Recursive bounded relevance-fill;
  Descartes `(Σk)² = 2Σk²`; integer curvatures = discrete depth levels
  (paragraph / section / chapter); δ ≈ 1.3057; open frontier. Routes what
  matters now; does not store content. This is the `scale`-toolset half that
  matters here.

### The frame

- **Lemniscate**: Wernicke loop (ingest) ⊗ Broca loop (produce), crossing at
  the "proper usage" node where genre rules are applied. Convergence = a clean
  crossing. Same object as `L_(I|O)` / the `{4:8:4}` NOW.
- **Genre = a field configuration** (domain Ω + boundary conditions): paper
  (front-to-back pressure gradient), résumé (parallel equal blocks → lattice,
  not gasket), memo (inverted pyramid), tutorial (a pipe, laminar), proof (a
  DAG, no eddies).
- **Navier–Stokes, hyperdimensional, no free surface** models context flow into
  the enclosed genre domain: `∇·u = 0` (context conserved, redistributed not
  lost), pressure p(x) = "how much context wants to be here" → block sizes,
  viscosity = readability, Reynolds ~ SCALE. **High Re → turbulent → eddies,
  and the eddies are the sections.** Turbulence here is structure, not a defect
  (the `COMPLEX_TURBULENT_FLOW` verdict, reused).

### Frustrated spirals

A clean spiral has monotone radius and constant pitch (a laminar topic). A
**frustrated spiral** is one where the local "step out by θ" rule cannot be
satisfied globally — it reverses along a **cross structural support** (a strut =
the stable⊥unstable manifold cross of the hub saddle at σ = ½, λ ≈ 6). It comes
**in** along the stable manifold, lingers near the fixed point, is flung **out**
along the unstable one — homoclinic winding, not a fold-free coil. Near the hub
the outbound and return steps are exponentially close (a doubled thread, high
density); far out they separate. The return pass **interdigitates** the outbound
pass — the capture spiral drops into the gaps the auxiliary spiral left.
`d(radius)/d(step)` is non-constant — collapses near the hub, spikes in the open
bays; that disagreement measures the frustration. The connective at every
reversal is an adversative/return one (the NTD switch firing); each reversal
deposits a `WRAP`. The **stabilimentum** — the zigzag band across the hub — is a
deliberately frustrated cross-brace.

### The test bench — `boxkite_orbweaver_monad.py`

`OrbWeaverMonad` holds its own `MindsEye` / `PapersHands` / `BoxKite` (fast;
`sig 1`, 7 struts). `weave(text, scale, genre)` runs the full cycle. The heavy
WordNet sentence layer is optional (`weave_via()`); the default path uses a
crude text sniffer + the copied `_SENTENCE_TEMPLATES` so the **web cycle** is
what is exercised.

**What runs (structure, verified):**
- `reach` from SCALE: 1 / 2 / 3 → paragraph / section / chapter scaffold depth
  (via the `scale`-toolset gasket rung when importable, else `round(scale)`).
- Scaffold spiral (centre→out) and capture spiral (out→in) laid in opposite
  order; capture paragraphs interdigitate the scaffold signposts.
- Every block carries its outbound connective + radial move — the weave is
  self-describing about where the next block goes.
- Turbulence gate (≥ 3 near-equal relation peaks) fires the frustrated-spiral
  pivots (`pivot` + aciniform `WRAP`, then jump spoke).
- Genre = field config selecting the block set + reach cap.

**What is broken / degenerate (recorded, not hidden):**
- **The coherence measure saturates.** `cam_encode` on template-length text
  lights all 7 struts, so `paragraph ∩ its-radius` overlap = 7 = `paragraph ∩
  another-radius` for every case (`real_mean == ctrl_mean == 7.000`). Zero
  discriminating power — exactly the problem `rotary_rerun_boxkite_monad.py`'s
  own `__main__` flags; it moved to `sigma_self` / `trochoid_loss` deltas.
  **TODO: switch the orb-weaver measure to the sigma_self-delta form.**
- **The sniffer over-flags turbulence.** Hash-spreading content-word counts
  across 19 slots always yields ≥ 3 peaks → every input reads "turbulent". An
  honest turbulence read needs the real 19-dim WordNet `root_vector` via
  `weave_via()`.
- Output is repetitive — expected: the sentence layer is copied templates + a
  sniffer, not the real `constructor`. Paragraph *construction* is to move into
  `monad3_c.bin` and paragraph *usage* into the granular `.bin` files; that
  redesign follows this test.
